[.lead]
dml.init EMS events occur when the Device Management Layer (DML) fails initialization.

== dml.init.fail
*Severity*::
ERROR
*Description*::
This message occurs when the Device Management Layer (DML) fails initialization.
*Corrective Action*::
Retry the startup.
*Syslog Message*::
Firestorm initialization failed with error code (%d).
*Parameters*::
*error_code* (INT): Failure code.

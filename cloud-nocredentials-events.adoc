== cloud.noCredentials
*Severity*::
ERROR
*Description*::
This message occurs when a Cloud Volume ONTAP (CVO) instance fails to retrieve cloud credentials from a metadata server. The credentials are used in signing API requests to cloud databases such as AWS DynamoDB. The failure causes CVO to be deployed without cloud mailbox disks and with takeover/failback disabled.
*Corrective Action*::
Ensure DNS, cloud credentials, and security group are set up correctly on this ONTAP Cloud instance and correct them if necessary.
*Syslog Message*::
ONTAP Cloud instance failed to retrieve cloud credentials during early boot with error: %s.
*Parameters*::
*err* (STRING): Error message.

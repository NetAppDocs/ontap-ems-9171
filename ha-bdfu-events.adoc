= ha.bdfu events
:toc: macro
:toclevels: 1
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
ha.bdfu events are presented when the source node cannot reenable background disk firmware update (BDFU) on the destination node during storage failover (SFO) giveback or aggregate relocation, which typically does not require corrective action.

== ha.bdfu.notEnabledOnDest
*Severity*::
INFORMATIONAL
*Description*::
This message occurs during storage failover (SFO) giveback or aggregate relocation when the source node cannot reenable background disk firmware update (BDFU) on the destination node. BDFU will be reenabled automatically on the destination node after all the aggregates have been given back.
*Corrective Action*::
(None).
*Syslog Message*::
(None).
*Parameters*::
*nodename* (STRING): Destination node.

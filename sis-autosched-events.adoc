[.lead]
sis.autosched events are presented when a SIS volume operation could not be auto scheduled due to unexpected conditions, which typically does not require corrective action.

== sis.autoSched.failed
*Severity*::
ERROR
*Description*::
This event is issued when a SIS volume operation could not be auto scheduled due to unexpected conditions.
*Corrective Action*::
(None).
*Syslog Message*::
SIS operation for %s%s could not be auto scheduled: %s
*Parameters*::
*vol* (STRING): Path to a SIS volume
*volident* (STRING): To uniquely identify the volume in cases where volume name itself is insufficient.
*err* (STRING): Error message

[.lead]
extcache.bypassallocfailed events are presented when external Cache cannot be enabled due to a memory allocation error which typically does not require corrective action.

== extCache.BypassAllocFailed
*Severity*::
ERROR
*Description*::
This message occurs when External Cache cannot be enabled due to a memory allocation error.
*Corrective Action*::
(None).
*Syslog Message*::
External Cache Bypass was not enabled due to a memory allocation error.
*Parameters*::
(None).

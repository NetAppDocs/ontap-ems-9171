[.lead]
disk.diagnostic events are presented when oNTAP retrieves the diagnostic logs from the disk which typically does not require corrective action.

== disk.diagnostic.logs.saved
*Severity*::
NOTICE
*Description*::
This message occurs when ONTAP retrieves the diagnostic logs from the disk. The logs are saved at /etc/log/drive_failure_logs/.
*Corrective Action*::
(None).
*Syslog Message*::
Diagnostic logs retrieved for disk "%s".
*Parameters*::
*diskName* (STRING): Name of the disk.

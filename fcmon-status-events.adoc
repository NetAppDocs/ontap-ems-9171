[.lead]
fcmon.status events are presented when fCMON starts up, halts or is requested to print it's current state which is typically fixed by following the documented corrective steps.

== fcmon.status
*Deprecated*::
Deprecated as of Data ONTAP 9.2 because FCMON process has been removed.
*Severity*::
INFORMATIONAL
*Description*::
This message occurs when FCMON starts up, halts or is requested to print it's current state.
*Corrective Action*::
None.
*Syslog Message*::
FCMON is %s
*Parameters*::
*status* (STRING): The status of FCMON (initializing|running|sleeping|halted)

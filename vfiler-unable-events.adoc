= vfiler.unable events
:toc: macro
:toclevels: 1
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
vfiler.unable events are presented when during vFiler(tm) unit discovery, if one of the vFiler(tm) unit module initialization functions fails which typically does not require corrective action.

== vFiler.unable.initModules
*Severity*::
ERROR
*Description*::
This message occurs during vFiler(tm) unit discovery, if one of the vFiler(tm) unit module initialization functions fails.
*Corrective Action*::
(None).
*Syslog Message*::
Could not initialize modules for vFiler unit "%s".
*Parameters*::
*vfName* (STRING): The vFiler unit on the source.

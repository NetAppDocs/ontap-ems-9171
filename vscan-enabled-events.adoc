[.lead]
vscan.enabled events are presented when a Vserver or cluster administrator enables Vscan on a Vserver which typically does not require corrective action.

== vscan.enabled
*Severity*::
INFORMATIONAL
*Description*::
This message occurs when a Vserver or cluster administrator enables Vscan on a Vserver. Based on the configuration, subsequent client requests can trigger virus scanning.
*Corrective Action*::
(None).
*Syslog Message*::
Vscan is enabled on Vserver '%s'.
*Parameters*::
*vserverName* (STRING): Name of the Vserver.

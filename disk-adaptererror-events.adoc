[.lead]
disk.adaptererror events are presented when an adapter error is detected which typically does not require corrective action.

== disk.adapterError
*Severity*::
ALERT
*Description*::
This message occurs when an adapter error is detected.
*Corrective Action*::
(None).
*Syslog Message*::
Disk %s: unexpected adapter error 0x%x
*Parameters*::
*diskName* (STRING): Name of the device.
*error* (INTHEX): Adapter status.

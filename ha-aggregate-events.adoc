== ha.aggregate.ownershipChangeFailed
*Severity*::
ERROR
*Description*::
This message occurs when an aggregate ownership change has failed. This can occur during takeover or giveback.
*Corrective Action*::
Use the "storage failover show" command to view the corrective action.
*Syslog Message*::
The local node has failed to change the ownership of an aggregate.
*Parameters*::
*errorCode* (INT): Ownership change failure error code.

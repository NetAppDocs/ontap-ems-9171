= dump.bitmap events
:toc: macro
:toclevels: 1
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
dump.bitmap events are presented when during dump restarting and looking for the bitmap file and it is cannot locate, which typically does not require corrective action.

== dump.bitmap.fail
*Severity*::
ERROR
*Description*::
This event is generated during dump restarting and looking for the bitmap file and it is unable to locate
*Corrective Action*::
(None).
*Syslog Message*::
Missing bitmap files.
*Parameters*::
(None).

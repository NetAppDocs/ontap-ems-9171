== phdb.addedMailboxDisk
*Severity*::
NOTICE
*Description*::
This message occurs when Cloud Volume ONTAP (CVO) creates and adds a cloud mailbox disk. A cloud mailbox disk is a fake disk using Cloud Database such as AWS DynamoDB to store CVO non-share HA metadata.
*Corrective Action*::
(None).
*Syslog Message*::
Cloud mailbox disk unit number: %d with uuid: "%s" was created and added.
*Parameters*::
*unit* (INT): Unit number.
*uuid* (STRING): Disk UUID.

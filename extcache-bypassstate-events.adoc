[.lead]
extcache.bypassstate events are presented when external Cache Bypass is enabled/disabled which typically does not require corrective action.

== extCache.BypassState
*Severity*::
INFORMATIONAL
*Description*::
This message occurs when External Cache Bypass is enabled/disabled.
*Corrective Action*::
(None).
*Syslog Message*::
External Cache Bypass is: %s.
*Parameters*::
*description* (STRING): State of External Cache Bypass

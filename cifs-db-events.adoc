== cifs.db.v2.exists
*Severity*::
ERROR
*Description*::
This message occurs when a CIFS server fails to be removed on the secondary site for an SVM in a MetroCluster configuration or SVM DR setup. The stale CIF server might cause issues when it is reprovisioned.
*Corrective Action*::
If this is a SnapMirror or MetroCluster environment, run the "snapmirror resync" command or the "metrocluster vserver resync" command respectively to resynchronize the Vserver configuration.
*Syslog Message*::
Stale CIFS server exists and may cause issues when reprovisioned. Vserver: %s Cifs Server: %s Error: %s.
*Parameters*::
*reason* (STRING): Reason for the failure.
*Vservername* (STRING): Name of the Vserver.
*cifsservername* (STRING): Name of the cifs server.
